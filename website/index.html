An API workspace that stays on your desktop

Understand an existing API, organize repeatable requests, and work with AI when it helps. Core scanning, browsing, and request workflows are available without an AI provider.

Find API endpoints

Scan supported Java, JavaScript/TypeScript, and Python projects, or read OpenAPI 3 definitions from GitHub repositories, without building the project.

Prepare and test requests

Explore a searchable API catalog, configure environments and parameters, review a request, and send it when you are ready.

Use optional AI assistance

Search APIs in natural language, plan request inputs, or draft API documentation with Ollama, Claude, or an OpenAI-compatible provider.
